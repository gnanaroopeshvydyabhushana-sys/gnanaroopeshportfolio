# Personal Portfolio Website

## 📌 Project Overview

This project is a personal portfolio website developed using **HTML5 and CSS3** as part of an HTML & CSS internship project. It introduces me, showcases my technical skills and academic projects, and provides contact information in a clean, professional design.

## 🎯 Objectives

- Create a professional personal portfolio website.
- Present my profile, education, technical skills, and projects.
- Practice HTML5 structure and CSS3 styling.
- Build a responsive layout for desktop and mobile devices.
- Improve my web development skills through practical implementation.

## ✨ Features

- **Home:** Introduction and career profile.
- **About Me:** Personal and educational information.
- **Skills:** Displays technical skills and technologies.
- **Projects:** Showcases academic and personal projects.
- **Contact:** Provides contact and professional profile links.
- **Responsive Design:** Adapts the layout to different screen sizes.
- **Modern UI:** White and blue colour theme with clean styling and hover effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox/Grid
- CSS Media Queries
- Visual Studio Code

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Explore the different sections of the portfolio.
5. Resize the browser or use mobile view to check the responsive design.
